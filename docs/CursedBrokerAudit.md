## How a curse buffs an item

A curse is on the item, like a void item's "corrupts all X": every copy you hold or pick up later is cursed. Cursed copies count as **copies × Mult + Add** in the game's *effective* stack count (`Inventory.UpdateEffectiveItemStacks`), which is what every item reads, so the item's own stacking delivers the buff.

- **×2**: linear per-stack items (damage, duration, charges): exactly double.
- **×2 +1**: items whose first copy is worth more than later ones (e.g. Harvester's 8 (+4) heal: 1 copy → 3 = 16, double), or hyperbolic ones that need extra copies to reach about double.
- **×3**: items where stacking only scales a secondary part (Ukulele targets/range, Warbanner radius) or is steeply hyperbolic (Lucky Shot, Inhibitor, Healing Tempo).
- **Custom**: Dio's Best Friend and Pluripotent Larva keep their count; each copy revives twice instead.
- **Not listed** (other mods' items): ×2, described as "every per-stack effect doubled".

Eligible: White, Green, Red, Boss (yellow), and Void White/Green/Red/Boss. Excluded: hidden, unremovable, Scrap, world-unique, consumed-on-use items (Power Elixir), Regenerating Scrap, Ominous Loan Note, the Alloyed Collective power items and Junk. Lunar, Hex, Page and Food tiers are never offered. Later-DLC rows only apply if the item's runtime tier is eligible.

## Penalty pool

One penalty per curse, rolled per item the first time a player sees that item at a broker (kept for that broker, so reopening can't reroll). Whites roll the lower half of each range, greens the lower 70%, Red/Boss/Void Red the upper 70%. Penalties of the same kind stack multiplicatively (reductions) or additively (increases). They last the whole run, even if the item is lost.
